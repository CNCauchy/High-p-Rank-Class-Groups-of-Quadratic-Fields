6. Mechanical inequality review
--------------------------------

CubicLowerBound:
  B*X <= A*N(X)^3 with A,B>0 gives
  N(X) >= (B/A)^(1/3)*X^(1/3) over nonnegative real coercions.
  The theorem instantiates A=comparisonConstant and B=mainConstant^3.

good_count_lower_bound:
  2*m*H^2 <= raw
  thin <= k*H
  k*H <= m*H^2
  raw <= good+thin
  therefore 2*m*H^2 <= good+m*H^2, so m*H^2 <= good.

height/count chain:
  good <= N(D*H^6)
  D*H^6 <= X and monotonicity imply N(D*H^6) <= N(X)
  X <= C*H^6 and m*H^2 <= N(X) imply
  m^3*X <= C*(m*H^2)^3 <= C*N(X)^3.
